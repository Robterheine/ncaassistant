# Manual tests MAN-65 to MAN-71: execution record

Software: NCA Assistant v1.9.0, working tree at commit 716531e plus the document changes of the release (validation run before the manual tests: 625 automated tests passed, 84 manual skipped; the two open failures were the release manifest and the document counts, both regenerated afterwards).
Date: 7 October 2026. Environment: macOS, R 4.6, the app run from the project folder on localhost (port 3939), in the built-in browser of the Claude desktop app.
Tester: an AI agent (Claude Sonnet 5.5) following the procedure of each test in `validation/validation.R`. An agent is not an independent tester; see section 1.4 of the IQ/OQ/PQ protocol.
How it was done: the examples were loaded, processed and run with the page's own buttons (Load example, Process Data, Run Complete BE Analysis, Download Analysis Record). Design, approach and covariate choices were set through the page's dropdown widgets, and the two changed files of MAN-68 and MAN-70 were made from the app's own example download and attached to the real file input. The records were fetched from the running session and unpacked in a separate folder; MAN-66 and MAN-67 were run with `Rscript` in fresh R sessions, without the app.
MAN-66 and MAN-68 were run by hand once, and the product owner then had them automated: REC-BE-18 repeats MAN-66 (the real record, unpacked into an empty folder, run with source() in a fresh R session) and REP-DES-11 repeats MAN-68 (the uploaded multi-group file through the real module, with the complete message and blank result outputs). They are no longer manual tests; the rows below record the hand run.

Observations (not defects):
- After a study with a 4×2 structure (four sequence labels, two periods) the design dropdown keeps the design chosen earlier in the session, because the detected structure matches none of the design codes, so nothing is pre-selected. The refusal then names the periods or the sequences of whichever design is still selected. The messages are correct for the selected design.
- The first refusal in MAN-68 came with the design left on 2×2×4 from the previous test: "2 periods (expected 4)". Selecting 2×2×2, as the test says, gave the sequence message above.

## Decision of the product owner

The product owner asked for the manual tests to be executed by the agent. They are therefore carried out as for v1.8.0: the record rests on the agent's execution alone, and an agent is not an independent tester.
